# SIMD Research Project

&nbsp;

I probably said something in the last blog about another post coming soon. Yeah... I got a bit distracted, and then school started. To be fair, I have been working on a project in my free time that I do plan on making a post about.

Well, now I have something to make a post about. I completed a group project in my introductory engineering class. We had the opportunity to research anything related to engineering. Coming into the assignment, I had already set my mind on SIMD because I have been using it a lot recently. I understood how to use SIMD but not how it worked deep down. So I searched for a group of people in my class that were interested in SIMD and its architecture. After about a day, I got my group of 2 other people, Dax Wong and Jean Barrera.

The group project started slow, but there was always progress being made. The last couple of days were in a bit of a rush to finish the poster, but we still had a lot of fun. At the beginning of the project we had loosely set tasks for everyone to do.

Dax Wong researched the history of SIMD and other aspects of SIMD. They also made the poster, including styling, putting it together, sorting, and just about everything when it comes to the visuals.

Jean did a lot of research relating to specialized instructions, key features, instruction sets, and methods of programming. They also came up with the wonderful title for the poster.

I programmed the example, collected data, created the graph, and researched what SIMD is and how it works (architecture). For my program, the group together chose to use NumPy. We chose NumPy because the class is just an introductory one and the code doesn't need to be anything advanced. I was a bit surprised how easy it was to use SIMD on NumPy. I thought I would have to install some special version of NumPy.

I am super happy with how the poster turned out, and everyone in the group put in so much effort. There was so much stuff everyone researched and wanted to add to the poster, but we had to keep in mind how much space was left on the poster. In the end I think we might have overdone it and probably should have left some more empty space. So here it is:
